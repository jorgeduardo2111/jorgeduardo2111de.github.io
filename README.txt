PORTAFOLIO WEB — JORGE EDUARDO NAVARRO

Archivos:
- index.html: sitio web completo, adaptable a móvil y escritorio.

Cómo abrir:
1. Descomprime el archivo ZIP.
2. Abre index.html en Chrome, Safari, Edge o Firefox.

Cómo personalizar:
- Edita index.html con Visual Studio Code o cualquier editor de texto.
- Los proyectos aparecen como casos demostrativos basados en el perfil de la hoja de vida. Antes de presentarlos como proyectos ejecutados, agrega evidencia real (capturas anonimizadas, diagramas, repositorios y resultados comprobables).
- Puedes agregar enlaces de LinkedIn y GitHub en la sección Contacto.
- Para publicarlo gratis, puedes subir index.html a GitHub Pages, Netlify o Cloudflare Pages.

Privacidad:
- El sitio muestra el teléfono y correo que aparecen en la hoja de vida. Si prefieres no publicar esos datos, reemplázalos antes de subirlo a internet.
